# Learnings: 0058, the `assistant` platform module and its status

- **rustls with two providers panics.** rig-bedrock turns on the AWS SDK's `default-https-client`, which enables rustls' `aws-lc-rs` feature beside the `ring` everything else uses. With both, `rustls::ClientConfig::builder()` (which redis uses for `rediss://`) panics: "Could not automatically determine the process-level CryptoProvider". sqlx, reqwest and the AWS SDK name their provider and are fine. `app_bus` now installs ring as the process default before building a redis client (`install_crypto_provider`). Feature unification only bites when the build set includes `assistant` (e.g. `cargo test -p app-bus -p assistant`, or the workspace): `cargo test -p app-bus` alone won't reproduce it.
- **Module configuration** lives in `server::config::AppConfig` (figment layering), but `Composition::modules()` takes no arguments, so a module needing config takes a `fn() -> Settings` (`assistant::module(config::agent)`), called when its provider is built. `config::agent()` re-reads the config without validating; every serving binary has already run `AppConfig::load()`.
- **Config tests that read env vars** must run inside `figment::Jail::expect_with` (server's dev-dependency `figment/test`): Jail serialises them, otherwise one test's `APP_*` leaks into another's extraction. Clippy wants `#[allow(clippy::result_large_err)]` on the test module for Jail's closures.
- **Every SPA screen asks for the assistant's status** from the header, so `vitest.setup.ts` and `screens/main.tsx` answer `{ on: false }` by default. A sign-in test whose fake API refuses every token must refuse that request too, or the `200` marks the token accepted (`Session.accepted`) and the anti-loop logic behaves differently (`catalogFor` in `src/test/sign-in.test.tsx`).
- **`make check-init`** pins the app's operations: a platform operation must be added to `platform_ops` in `scripts/check-init.sh`, and `scripts/init.sh` rewrites `modules.rs`, `router.tsx` and `screens/scenarios.ts` wholesale, so a platform module or page must be added to those heredocs. Naming a reference module or the template in any file outside `crates/reference/` and `docs/platform/` (this `.factory/learnings/` too) fails its word scan.
- A `docker build` started while `make spec` rewrites `frontend/openapi.json` can copy a truncated spec: the frontend stage then fails with missing `@/api/...` modules. Rebuild once the tree is still.
- `aws-lc-sys` 0.47 built fine in `rust:1.97.1-slim-bookworm` and on the Graviton (aarch64) box; no Dockerfile change needed.
- `pnpm run screens`' `edit-note-conflict.phone` scenario failed once in this run (not investigated; the assistant scenario passed). Screens are not part of CI.
