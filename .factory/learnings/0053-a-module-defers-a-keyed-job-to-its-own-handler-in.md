# Learnings: 0053 deferred jobs

- **Deferred jobs live in `messaging.job`** with `deferred = true`, `queue = event_type = J::NAME`, `outbox_seq = 0`, and at most one pending row per `(queue, key)` (`job_deferred_key_idx`, partial: `deferred AND dead_at IS NULL`). `PgDeferredJobs::write` is an `INSERT .. ON CONFLICT (queue, key) WHERE deferred AND dead_at IS NULL DO UPDATE`: Postgres infers a partial unique index only when the `ON CONFLICT` repeats its predicate.
- **A reschedule bumps the row's `version`**, and the worker's `complete`/`fail` now match `id AND version`. That is what makes a run under way when its job is rescheduled or cancelled roll back instead of deleting the new job. Event jobs never change version, so they are unaffected.
- `Handlers::claims()` is what a worker claims (subscriptions plus deferred job types); `Handlers::subscriptions()` stays what `migrate` registers and `check_subscriptions` checks. Don't feed job types into `messaging.subscription`.
- `impl dyn DeferredJobs { async fn defer<J>(..) }` gives a generic method on a trait object: the trait itself stays object-safe (`write`/`remove` take an erased `PendingJob`).
- `Note::restore` now takes 8 arguments; clippy's `too_many_arguments` is allowed on it with a reason.
- `frontend/src/api/` is gitignored (generated by `make generate`, ADR 0023): only `frontend/openapi.json` is committed, despite tickets saying "commit `frontend/src/api/`".
- `.sqlx` refresh without touching the shared dev DB: a private `postgres:17-alpine` on its own port, every schema migrated by `cargo bin sqlx migrate run --source <crate>/migrations --database-url "$URL?options=-csearch_path%3D<schema>"` (common/db's is `messaging`), then `SQLX_OFFLINE=false DATABASE_URL=$URL cargo bin sqlx prepare --workspace -- --all-targets`. Then `make -o db-wait -o db-up check-changed DATABASE_URL=.. TEST_DATABASE_URL=<same server>/postgres`.
- `EditNoteRequest` replaces the whole author-chosen state, so leaving `archiveAt` out of an edit clears it (and cancels the job). An edit form that doesn't know `archiveAt` must send it back.
