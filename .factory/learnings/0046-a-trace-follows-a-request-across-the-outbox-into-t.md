# Learnings: 0046, a trace follows a request across the outbox

- **Parallel tests using `Traces::install()` (thread-local subscribers) lose spans intermittently** without a global subscriber: tracing-core caches each callsite's interest and the global max level across threads, and concurrent rebuilds as per-thread dispatchers come and go can leave a span disabled. `Traces::install` now sets, once, a global no-op subscriber that wants every level and answers `Interest::sometimes()`, so each span asks its own thread's subscriber. Before it, `cargo test -p app-db --test delivery` failed about 1 in 2 runs; after, 6 of 6 passed.
- **A job's span is created with `parent: None` and then `set_parent(..)`**: the extracted envelope context, or an empty `Context::new()` to force a new root. Without `parent: None` it would become a child of whatever span the worker's poll is in.
- **The relay's span starts only once the batch is non-empty**: an idle worker polls every interval, and a span per empty poll would export noise.
- **`make prepare` needs `make migrate`, which compiles the workspace offline**, so after changing a `query!` the build fails before the DB can be migrated. What worked: temporarily revert the query, `make migrate` and `./scripts/migrate-unregistered.sh`, restore it, then run `SQLX_OFFLINE=false cargo bin sqlx prepare --workspace -- --all-targets`. If one crate's queries fail (here the module template's, when its schema was missing), prepare deletes every `.sqlx` file. Restore the unrelated ones with `git checkout` and keep only the changed query's file.
- A private Postgres for the worktree: a compose override file mapping `5446:5432`, plus `COMPOSE_PROJECT_NAME`, `COMPOSE_FILE`, `DATABASE_URL` and `TEST_DATABASE_URL` pointing at it.
- `pgrep -f '<pattern>'` in an until-loop matches its own shell's command line, so it never ends.
- In the journeys, `App::seeded` leaves the seeds' events undelivered: a trace test must `run_pending_events()` before installing `Traces`, or the seeds' jobs show up, each in a trace of its own.
